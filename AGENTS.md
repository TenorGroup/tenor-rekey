- **NEVER write real secrets into code/comments/tests.** No real MIFARE keys or real card UIDs from the founder's cards. The repo is public with scrubbed history. Use placeholder hex (e.g. `AABBCCDDEEFF`) in examples/tests. The orchestrator runs a pre-push key-leak guard; a real key in the diff blocks the commit.
- **No em-dash / en-dash anywhere** (code, comments, docs, commit-adjacent text). Use a plain hyphen `-`. This is a hard Tenor lock.
- **No mentions of Claude / Codex / AI / "generated by"** in source comments or any text that will be committed. Commit prose (written by the orchestrator) is natural, no AI attribution.
- Keep GPL license + copyright notices intact on any code imported from RfidResearchGroup (the Chameleon CLI classes, the C attack tools).

## Style
- Swift: match the existing files under `app/Sources/Engine/` and `app/Sources/Views/` (PascalCase types, actor-based engine, `@MainActor` model). Do not refactor outside your task's scope.
- Python: match `probe/x7d.py` / `probe/x7lib.py` idioms (a `Daemon` class with a `METHODS` tuple, `handle()` dispatch, `_drop()` on `OSError`, newline-delimited JSON on stdin/stdout).

- Minimum code that solves the task. No speculative abstractions.
